## 📝 論文研究計畫書（Proposal）架構演練

_(依據張恆瑜老師提示：以「現象為師」開頭，重點放在問題的重要性，嚴格控制在 6 頁內)_

### 一、 研究背景與動機（以現象為師、客觀數字破題）

- **客觀數字與痛點：** 全球高齡化帶來慢性傷口（壓瘡、糖尿病足）醫療支出黑洞；同時，睡眠障礙與失智症人口激增。傳統醫療器材功能單一且極度昂貴。
    
- **Uniqueness（您的獨特性方法）****：** 如果沒有本研究提出的平台化策略，醫材廠只能陷入代工與價格戰。本研究提出透過「第一性原理」，利用共享邊緣運算（Realtek/Nuvoton）與 CMOS 晶片技術，達成極致的 BOM 成本控制，以此作為商業競爭與併購決策的基石。
    

### 二、 理論與 missing link 矩陣（尋找調節或中介變數）

在管理研究中，我們要找出技術與商業成功的 **Puzzle（謎題）**：

```
[ 自變項 (X): 平台化研發/併購策略 ] ───► [ 中介變數 (M): 臨床價值鏈精實度 ] ───► [ 因變項 (Y): 企業競爭優勢與商業獲利 ]
                                                  ▲
                                                  │
                                        [ 調節變數 (W): 國際醫療法規/健保給付制度 ]
```

- **中介變數（Mediator）：** 策略如何透過「消除臨床流程中拆除敷料、盲目清創的浪費」來影響企業獲利。
    
- **調節變數（Moderator）：** 健保給付（如 DRGs、論質計酬）或睡眠消費市場的法規門檻，如何加速或減緩平台策略的成功契機。
    

### 三、 研究方法（個案研究與深入訪談）

- 長庚 EMBA 最強大的資源在於**臨床實務的對接**。論文將深度訪談長庚醫院整形外科醫師、長照機構經營者（針對傷口平台），以及睡眠醫學中心、醫材 M&A 專家，來驗證商業模式畫布（Business Model Canvas）的九大要素與併購風險評估。
