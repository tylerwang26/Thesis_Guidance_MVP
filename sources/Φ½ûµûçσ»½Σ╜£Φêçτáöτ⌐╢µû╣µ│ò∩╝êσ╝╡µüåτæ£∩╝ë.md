# 一
- 看別人文獻要發現有什麼跟你不同 ＝自己的論文要跟別人有那一點不同？
- When, Do...、Review article、4W1H 的論文題目建議不要：
- 是否真的需要花時間研究做成一本論文？能通過下列測驗嗎？
  - [ ] 能應用在重要決策？→ ==如果没有你這個方法，難道没有解決方法？你的Uniqueness==
  - [ ] 能改善制定管理決策的品質？→ ==質或量的品質==
  - [ ] 能實踐實務的運用？→ ==如何用在你的領域、可否用在別的領域==
- 常犯毛病： 前無古人後無來者，很危險！
- 重點要放在： 此問題是否具有重要性！
- 怎麼開頭？1. 客觀數字(科學證據)；2.以現象為師
- 目的與動機：
  - 目的：（寫在起和合）這研究回答了什麼問題？Question or Problem? 
    ex: 今年公司獲利為什麼下降？（需要答案）v.s. 公司獲利連續三年下降（ 需要解決）
  - 動機：（寫在承和轉）為什麼要做這個研究？ 

$$
中・心・思・想  → 很重要
$$

- 論文第一章及第五章是大多口委必看的

# 研究背景與目的

- 以現象為師
	- 「男不壞，女不愛」，是真理還是迷思？
	- 跳槽是好還是不好？
- 以理論為基礎
	- missing link → 要去找新的==自變項(independent variable)== 
	- inconsistency → 要去找==調節變數(moderator)== → x越多, y越小（反向）
	- puzzle → 要去找==中介變數 (mediator)== → x 找 m，再由 m 找 y
- Rule of Thumb（經驗法則）：
	- 主流期刊出現不到5篇：還不熱門
	- 10：
	- 25：
- 如何進行一個學術/實務研究
	- 從自己的專業或興趣著手
